# Probability Detective Project Rules

This repository is the public source for Taskmarket task TSK-MG8KF2RH: an age-12 probability education website.

- Keep the deliverable static/client-side, dependency-light, public, and independently runnable.
- Implement all three required activities: coin laboratory, dice investigation, and fair-game designer/final challenge.
- Preserve probability correctness: observed frequency is evidence, not a promise; theoretical probability does not change because of a streak; larger samples often get closer but are not guaranteed to improve every time.
- Core actions must be keyboard accessible and responsive at 360px, 768px, and 1280px.
- Do not add accounts, analytics, ads, payments, open chat, uploads, child data collection, remote grading, or runtime AI/API dependencies.
- Record only tests actually run. Keep evidence under `evidence/` and documentation at repository root.
- Commit clean slices and push each completed slice to `main`.
