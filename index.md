- `index.html` — learner-facing single-page lesson shell.
- `styles.css` — responsive and accessible visual system.
- `src/` — learning content, probability model, and UI/controller code.

- `.github/workflows/pages.yml` — free GitHub Pages deployment workflow.
- `README.md` — exact setup/build/preview/deployment commands, browser support, and limitations.
- `EDUCATOR_GUIDE.md` — objectives, prerequisites, walkthrough, adaptations/co-play, limitations, references, and offline follow-up.
- `ARCHITECTURE.md` — state/model/content architecture notes.
- `TEST_REPORT.md` — acceptance mapping and observed test evidence.
- `SCREENSHOT_WALKTHROUGH.md` — numbered visual walkthrough.
- `SUBMISSION.md` — concise reviewer path and public URLs.
- `LICENSE` / `THIRD_PARTY_NOTICES.md` — licensing and attribution.
